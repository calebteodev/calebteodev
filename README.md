## Featured Projects

### [The Cost of Remittance from Singapore, 2011–2025](https://github.com/calebteodev/Cost-of-Remittance-from-Singapore) data-analytics study of what migrant workers pay to send money home
A quote-level analysis of 230,652 World Bank Remittance Prices Worldwide quotes across 354 corridors, joined with seven other datasets, tracking the cost of sending USD 200 against the UN SDG 10.c targets, splitting the price into fee and FX margin, and modelling which corridor characteristics are associated with lower costs. Built August–October 2026 for CS4132 Data Analytics and **awarded A+**, with the lecturer, Mrs Phylliscia Lee, highlighting its clear research questions, thoughtful analysis and well planned visualizations. Python · pandas · statsmodels · Jupyter. Includes the full report and an evidence appendix. (All rights reserved.)

### [SynapseUX](https://github.com/calebteodev/Synapse-UX) fully adaptive & dynamic Android launcher
A full-stack Android launcher that reimagines the home screen with an adaptive, automatically customized UX tailored to the user's usage preferences through analysing usage data. Built February–April 2026 for CS4131 Mobile Application Development and **awarded A+** by the lecturer, Mr Claude R. Chua. Kotlin · Jetpack Compose · Gradle. Includes release APKs, a video demo and full documentation. (GPL-3.0 (code), All rights reserved (documentation))

### [The Molecular Genetics Study Guide](https://github.com/calebteodev/The-Molecular-Genetics-Study-Guide) interactive simulation and exam-prep applet for O Level Biology (Singapore)
A Java applet study guide with step-by-step transcription and translation simulators (DNA → mRNA → polypeptide), a codon/amino-acid model and an AI-integrated module for querying and generating practice papers. Built August–October 2025 for CS3233 Object Oriented Programming II **awarded A+**, with the lecturer, Mr Claude R. Chua, highlighting its originality, effective use of interfaces and abstract classes, and intuitive GUI. Java · JavaFX · Maven. Includes release JARs, a video demo and full documentation.
